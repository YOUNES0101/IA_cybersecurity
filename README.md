# 🛡️ AI for Cybersecurity

Coursework, labs, and notes from my **AI for Cybersecurity** module
(*IA pour la cybersécurité*). This repository documents how I applied
machine learning to security problems: filtering spam, detecting
phishing, and analyzing network traffic for intrusions.

## 📚 Module overview
- **Phase 1: Supervised learning.** Classifying threats from labeled data
  (spam vs. legitimate, phishing vs. safe).
- **Phase 2: Unsupervised learning.** Finding structure in unlabeled
  network traffic with PCA and clustering.
